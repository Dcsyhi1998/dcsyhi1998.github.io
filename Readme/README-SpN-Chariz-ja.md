# Airaw Split Native

CarPlay対応アプリをスプリットビューで表示するためのAirawアドオンです。

Airaw Split Nativeを使用すると、CarPlay純正アプリのマップやミュージックなどのアプリをiPhoneにあるアプリと同時に表示をします。

## 動作要件

購入前に、以下の内容をご確認ください。

- iOS 16.0以降が必要
- iOS 14およびiOS 15は非対応
- [Airaw](https://chariz.com/buy/airaw) 1.7.0以降が必要
- Rootless脱獄環境が必要
- Airaw Split Nativeは単体では動作しません

本製品はAiraw用のアドオンです。設定アプリのトップ画面に、Airaw Split Nativeの個別項目は表示されません。

設定は「設定 → Airaw → スプリットビュー（純正）」から開きます。

## 主な機能

- CarPlay対応アプリをスプリットビューで表示
- アプリごとにスプリットビューの有効・無効を設定
- アプリライブラリから対象アプリを追加
- スプリットビューの初期比率を調整
- フルスクリーン時の拡大率を設定
- 最大化したときのみホストメニューを表示(アプリの拡大や縮小やSplit Viewボタンなどの表示)

## 使用方法

1. Airaw Split Nativeをインストールします。
2. 「設定 → Airaw」を開きます。
3. 「スプリットビュー（純正）」を選択します。
4. スプリットビューで使用するアプリを有効にします。
   　　※CarPlay純正アプリでない場合、アプリライブラリから追加してもスプリット対象にはなりません。
   　　　アプリライブラリから追加するアプリはCarPlayに対応した純正アプリを追加しないといけません。
   　　　純正でないアプリを追加しても何も機能しません。
   　　　純正アプリでないアプリをSplit Viewをしたい場合はAiraw Split View 標準が必要になります。

## Airaw Split Standardとの違い

Airaw Split Nativeは、CarPlay対応アプリをスプリットビューで使用するためのアドオンです。

CarCastやCarBridgeから追加した非CarPlayアプリをスプリットビューで使用する場合は、Airaw Split Standardが必要です。

NativeとStandardは別々のアドオンです。使用したいアプリの種類に応じて選択してください。どちらもiOS 16以降が必要になります。

## 互換性と制限事項

- 対応OS：iOS 16.0以降
- 非対応OS：iOS 14、iOS 15
- 必須パッケージ：Airaw 1.7.0以降
- 対応環境：Rootless脱獄環境
- アーキテクチャ：arm64e
- 設定場所：Airaw → スプリットビュー（純正）

Airaw Split Nativeの動作は、AirawのCarPlay実行機能に依存します。Airawも最新バージョンへ更新してください。

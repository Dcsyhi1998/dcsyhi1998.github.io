HomerRun

ステータスバーのモニター
Status bar monitor

ステータスバーをキャラクターが走ります。CPU の使用率、または通信量に合わせて走る速さが変わるので、端末の忙しさが目の端で分かります。

A character runs across your status bar. It speeds up with CPU load or network traffic, so you can feel how busy the device is out of the corner of your eye.

iOS 14+ arm64 / arm64e rootless v1.1

走る速さ

Run speed

アニメーションは 1 コマずつ 負荷に応じた間隔で進みます。ゆっくり歩くくらいから全力疾走まで、値の変化がそのまま速さになります。

Frames advance one at a time at an interval derived from the current load, so the value maps straight onto how fast the character moves — from a slow walk to a full sprint.

CPUCPU 初期値DEFAULT

プロセッサの負荷に追従します。ラベルには使用率が出ます。

Follows the processor load. The label shows the usage percentage.

ネットワークNetwork

通信量が増えるほど速く走ります。ラベルには転送レートが出ます。

Runs faster as traffic increases. The label shows the transfer rate.

できること

Features

長押しで端末情報 Long press for details CPU、メモリ、バッテリー、ストレージ、ネットワークをまとめて表示。 CPU, memory, battery, storage, and network in one panel.
キャラクターを差し替え Swap the character コマ画像を入れたフォルダを置くだけで一覧に並びます。 Drop a folder of frames in and it appears in the list.
位置とサイズ Position and size 画面左上を基準に、置きたい場所と大きさを決められます。 Place it anywhere, measured from the top left of the screen.
ラベル Label 表示のオン／オフ、文字サイズ、文字色、フォント名。 Show or hide it, then set size, color, and font name.
横画面では隠れる Hidden in landscape 横向きのときは自動で消え、アニメーションも止まります。 It disappears in landscape and the animation stops.
日本語と英語 English and Japanese 設定画面も情報パネルも端末の言語に合わせて表示。 Settings and the info panel follow the device language.

使い方

How to use

1
HomerRun を入れる Install HomerRun

このリポジトリからインストールし、リスプリングします。

Install it from this repo, then respring.

2
有効にする Turn it on

設定 → HomerRun でスイッチをオンにします。

Open Settings → HomerRun and enable the switch.

3
走る速さを選ぶ Pick the run speed

Run speed で CPU かネットワークを選びます。初期値は CPU です。

Choose CPU or Network under Run speed. The default is CPU.

4
見た目を整える Tune the look

キャラクター、位置、サイズ、ラベルを好みに合わせます。

Set the character, position, size, and label to taste.

自分の画像を使う

Use your own frames

下のフォルダに「コマ画像を入れたフォルダ」を作ると、Select image の一覧に出てきます。ファイル名の順に再生されます。

Create a folder of frame images inside the directory below and it shows up in the Select image list. Frames play in filename order.

/var/jb/Library/PreferenceBundles/Homero.bundle/Gifs

設定画面の Open images folder から Filza で直接開けます。追加したあとはリスプリングしてください。

Tap Open images folder in settings to jump there in Filza. Respring after adding frames.

1.1

iOS 14 – iOS 26 に対応。走る速さを CPU と通信量から選べるようになり、1 コマごとに負荷を反映する方式へ変更（初期値は CPU）。長押しで CPU・メモリ・バッテリー・ストレージ・ネットワークを見られる情報パネルを追加。日本語と英語に対応。横画面では非表示に。Cephei と libcolorpicker への依存をやめ、色は標準のカラーピッカーで選ぶようになりました。iOS 26 で画像選択画面が開かない問題と、テキストカラーが反応しない問題を修正。

Support iOS 14 – iOS 26. Run speed can now follow CPU load or network traffic, mapped per frame instead of a fixed loop (CPU is the default). Added a long press info panel with CPU, memory, battery, storage, and network. English and Japanese. Hidden in landscape. Dropped the Cephei and libcolorpicker dependencies — colors now use the system color picker. Fixed the image picker not opening and the text color row not responding on iOS 26.

よくある質問

FAQ

キャラクターが見えません The character does not appear

設定でオンになっているか確認し、リスプリングしてください。横画面では表示されません。位置が画面外になっている場合は Position の値を戻してください。

Confirm it is enabled, then respring. It never shows in landscape. If the position moved off screen, reset the Position values.

タップが下のアプリに届きません Taps do not reach the app underneath

Device info の「長押しで詳細」がオンのとき、キャラクターが覆っている範囲だけタップを受け取ります。気になる場合はこのスイッチをオフにしてください。

While Device info → Long press for details is on, the small area covered by the character receives taps. Turn that switch off if it gets in the way.

バッテリー情報が出ません Battery details are missing

健全性や充放電回数は端末から読めないことがあります。読めない項目は行ごと省略されます。

Health and cycle count are not always readable. Any value that cannot be read is left out of the panel.

バッテリーは減りますか？ Does it drain the battery?

横画面や非表示のときはアニメーションとタイマーを止めています。表示中も 1 コマ単位の軽い更新だけです。

The animation and its timer stop while hidden or in landscape. While visible it only does light per-frame updates.

フォント名はどう調べますか？ How do I find a font name?

Label の「Browse font names」で一覧が出ます。名前をタップするとコピーされるので、Font name に貼り付けてください。空欄なら MarkerFelt-Thin になります。

Label → Browse font names lists them. Tap a name to copy it, then paste it into Font name. Leave it empty for MarkerFelt-Thin.

rootful は？ Is rootful supported?

現行は rootless 向けです。arm64 / arm64e、iOS 14 以降。

The current build is rootless. arm64 / arm64e, iOS 14 and later.

Keyboard dock

KBApp

キーボードのドックに、アプリとモジュールを並べます。起動、編集、翻訳、クリップボードまで、入力したまま手が届きます。

A dock on the iOS keyboard for apps and modules. Launch, edit, translate, and paste without leaving the keyboard.

iOS 14+ arm64 / arm64e rootless v1.7

できること

Features

設定 → KBApp で有効にすると、キーボード下部にドックが現れます。アプリ起動、編集モジュール、グループ、翻訳プリセットを自由に並べ替えられます。

Turn it on in Settings → KBApp. A dock appears at the bottom of the keyboard. Pin apps, editor modules, groups, and translation presets, then reorder them.

アプリ起動 Launch apps よく使うアプリをドックからすぐ開けます。 Open frequent apps straight from the dock.
編集モジュール Editor modules コピー、カット、ペースト、選択、Undo / Redo、カーソル移動。 Copy, cut, paste, select, undo / redo, and cursor moves.
翻訳 Translate 選択範囲または全文を翻訳。プリセットを追加できます。 Translate the selection or the whole field. Add presets.
定型文 Favorites よく使う単語を保存して、ワンタップで挿入。 Save frequent words and insert them in one tap.
クリップボード Clipboard 履歴を見返し、不要な項目を削除できます。 Review copied text and swipe to delete items.
レイアウト Layout 間隔、アイコンサイズ、下端からの距離を調整。 Spacing, icon size, and distance from the bottom.

使い方

How to use

1
KBApp を入れる Install KBApp

このリポジトリからインストールし、リスプリングします。

Install it from this repo, then respring.

2
有効にする Turn it on

設定 → KBApp でスイッチをオンにします。

Open Settings → KBApp and enable the switch.

3
ドックを組む Build the dock

Dock → アプリまたはモジュールから追加・並べ替えします。

Add and reorder items in Dock → Apps or Modules.

よくある質問

FAQ

ドックが見えません The dock does not appear

設定で有効になっているか確認し、キーボードを出し直してください。位置がずれているときは Layout の「下端からの距離」を調整するか、Debug でドックの範囲を確認できます。

Confirm it is enabled, then dismiss and show the keyboard again. If the position is off, use Layout → Distance from bottom, or Debug to see the dock bounds.

モジュールの色は変えられますか？ Can I change module colors?

Dock の Appearance で、カスタムカラー / システムカラー / 画像の色を保持、を選べます。

Yes. Dock → Appearance: custom color, system color, or keep the image color.

グループとは？ What is a group?

ドック上では1つのアイコンです。タップすると、入れたアプリやモジュールのメニューが開きます。空のグループのほか、編集グループ／翻訳グループのテンプレートも作れます。

A group is one icon on the dock. Tap it to open a menu of the apps and modules inside. You can start empty, or use the Editing Group / Translation Group templates.

設定を初期化できますか？ Can I reset settings?

設定画面右上のハートメニューから Reset Settings を選ぶと、設定を消してリスプリングします。

Yes. The heart menu at the top right has Reset Settings. It clears prefs and resprings.

rootful は？ Is rootful supported?

現行は rootless 向けです。arm64 / arm64e、iOS 14 以降。

The current build is rootless. arm64 / arm64e, iOS 14 and later.

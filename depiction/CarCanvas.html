使い方

How to use

1
IPA を入れるInstall the IPA

Releases から取得し、企業証明で署名してインストール（ESign など）。

Get it from Releases, sign with an Enterprise cert, then install (e.g. ESign).

2
キャッシュを作るCreate caches

CarPlay の壁紙で模様付き 6 枚を選び、キャッシュを作成。

On CarPlay Wallpaper, select the 6 patterned wallpapers to build caches.

3
上書きして再起動Overwrite & restart

履歴から Dark / Light を上書きし、iPhone の電源オフ再起動。

Overwrite Dark / Light from History, then power-cycle the iPhone.

よくある質問

FAQ

脱獄は必要ですか？ Do I need a jailbreak?

不要です。ただし企業向け証明書での署名が必要で、App Store / 個人証明 / AltStore では動きません。

No. Enterprise / In-House signing is required. App Store, personal certs, and AltStore will not work.

上書きしたのに壁紙が変わりません I overwrote caches but nothing changed

CarPlay が古いキャッシュを保持していることがあります。iPhone の電源を切って再起動してください。挿し直しだけでは足りないことが多いです。

CarPlay may keep old caches in memory. Power off and restart the iPhone. Replugging alone is often not enough.

書き出し先が見つかりません No export targets / caches missing

模様付き壁紙をまだ選んでいません。CarPlay で青 → 紫 → グレイ → 緑 → ブラウン → 赤の順に選び直してください。下段の単色はキャッシュを作りません。

Patterned wallpapers were not selected yet. On CarPlay, pick Blue → Purple → Gray → Green → Brown → Red. Bottom solid colors do not create caches.

IPA はどこから？ Where do I download the IPA?

GitHub Releases からダウンロードしてください。

Download from GitHub Releases.

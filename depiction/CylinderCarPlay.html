CarPlay Effects

Cylinder CarPlay

Cylinder のページめくりエフェクトを、CarPlay のホーム画面だけに。iPhone の SpringBoard はそのままです。

Cylinder page-swipe effects for the CarPlay home screen only. SpringBoard stays stock.

iOS 14+ arm64 / arm64e Lua effects

できること

Features

設定 → Cylinder CarPlay でエフェクトを選び、CarPlay を再接続するだけ。オリジナル Cylinder と同じ Lua スクリプトが使えます。

Pick effects in Settings → Cylinder CarPlay, then reconnect CarPlay. Uses the same Lua scripts as original Cylinder.

ページめくりPage swipeCarPlay ホームのスワイプにエフェクト。Animate CarPlay home swipes.
複数エフェクトCombine重ねがけやランダム再生に対応。Stack effects or randomize them.
Lua スクリプトLua scripts/Library/CylinderCarPlay から読み込み。Loads from /Library/CylinderCarPlay.
共存できるCoexistsSpringBoard 用 Cylinder と同時インストール可。Install alongside Cylinder for SpringBoard.

使い方

How to use

1
有効にするEnable it

設定 → Cylinder CarPlay をオン。

Turn on Settings → Cylinder CarPlay.

2
エフェクトを選ぶPick effects

Cube など、好きなページめくりを選択。

Choose Cube and other page effects.

3
CarPlay を再読み込みReload CarPlay

再接続するか、設定の再読み込みをタップ。

Reconnect, or tap Reload CarPlay.

よくある質問

FAQ

iPhone のホームも変わりますか？ Does this change SpringBoard?

変わりません。CarPlay 専用です。iPhone 側は元の Cylinder を入れてください。

No. This is CarPlay-only. Use original Cylinder for the iPhone home screen.

元の Cylinder と同時に使えますか？ Can I use this with Cylinder?

はい。こちらは com.apple.CarPlayApp だけに注入します。SpringBoard 用 Cylinder と共存できます。

Yes. It injects into com.apple.CarPlayApp only, so it can sit next to Cylinder on SpringBoard.

独自の Lua は使えますか？ Can I add my own Lua effects?

はい。/Library/CylinderCarPlay（rootless は /var/jb/Library/CylinderCarPlay）にフォルダを置けます。元の /Library/Cylinder も読みます。

Yes. Put packs in /Library/CylinderCarPlay (rootless: /var/jb/Library/CylinderCarPlay). It also reads /Library/Cylinder if present.

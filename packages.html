CarPlay 向けが中心です。Airaw 本体と有料アドオンは Chariz。Cylinder CarPlay と CarGlyph はこのリポジトリから導入できます。 Built around CarPlay. Airaw and paid add-ons are on Chariz. Cylinder CarPlay and CarGlyph install from this repo.

CarPlay

Airaw が基盤。アプリ追加・Split View・見た目は別パッケージです。 Airaw is the platform. Apps, Split View, and visuals ship as separate packages.

CarCast と CarBridge は同時にインストールしないでください。どちらか一方だけを使ってください。 Do not install CarCast and CarBridge together. Use one or the other.

Airaw

iOS 14–26 Chariz jp.dcsyhi.airaw

CarPlay のレイアウト、壁紙、ステータスバー、ウィジェット、フルスクリーンアプリ。Split View は iOS 16+ の有料アドオンです。モジュールウィジェットは iOS 14–26。HTML ウィジェットは iOS 14–15 のみ。 Customize CarPlay layout, wallpaper, status bar, widgets, and fullscreen apps. Split View is a paid iOS 16+ add-on. Module widgets work on iOS 14–26. HTML widgets work on iOS 14–15 only.
